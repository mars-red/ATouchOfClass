# Bundled recipe reference

[Manual](README.md) · [Catalog](catalog.md)

Generated from every recipe under the mod namespace. Names below are recipe IDs without the `atouchofclass:` prefix. Grids show rows from top to bottom; `.` is an empty slot. `#` prefixes an ingredient tag. Cooking times are ticks (20 ticks per second at normal speed). Shaped patterns can be positioned within a crafting grid as the game permits; shapeless ingredients may be arranged freely.

Use the catalog links or search this page for the item ID. Recipes listed here are the bundled defaults; data packs can override them.
