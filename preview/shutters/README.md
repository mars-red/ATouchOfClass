# Oak shutter model proposal

`oak_shutters_preview.png` renders three one-block shutters stacked vertically,
closed and opened 90 degrees with each hinge direction. The PNG is generated
from the accompanying Minecraft model elements, including their 22.5-degree
louver rotations. The game models and gameplay resources are generated by
`tools/generate_oak_shutters.py` from this geometry.

Each section is 16 units wide and tall, with a two-unit-deep frame. Two-unit
side stiles continue through the stack. Louvers repeat every two vertical
units. Only the exposed top and bottom have end rails: the bottom, middle,
top, and single models represent the four possible vertical connections.
Each section, including the angled louvers, fits inside its block in both
the closed and open positions.

All faces use the same vanilla texture mapping as **stripped oak wood**.
Minecraft names that texture `minecraft:block/stripped_oak_log`; vanilla's
`stripped_oak_wood` model uses it for both `side` and `end`. No end-grain
(`stripped_oak_log_top`) or plank textures are used.

Run `generate_preview.py` with Python, Pillow, and NumPy. It reads the local
Minecraft 1.21.4 client JAR; `MINECRAFT_CLIENT_JAR` can override its location.

Implemented behavior: placement sits flush against the clicked wall face
and chooses the hinge from the horizontal click position on that face.
Top/bottom clicks on an existing shutter extend its facing vertically.
Interaction sets the
entire contiguous vertical group to the clicked shutter's new open/closed
state. A group must share wood variety, facing, and hinge side; a gap or
mismatch ends the group. Visual connections use the same grouping rules.
Breaking a shutter removes only that block and restores exposed end caps
on its neighbors. Survival breaking drops one shutter; creative drops none.
The recipe uses `WSW` in two rows, where W is oak planks and S is a stick,
producing eight shutters. Obtaining oak planks unlocks it. Future wood variants
should call `generate_recipe(wood)` in `tools/generate_oak_shutters.py` to use
the same pattern and yield with their matching planks and recipe unlock.
