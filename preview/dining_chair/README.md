# Dining chair models

The approved oak concept is implemented for all twelve vanilla wood types as
`atouchofclass:<wood>_dining_chair`, including bamboo, crimson, and warped.
The files in this directory retain the original design preview; production
assets and collision geometry are generated by `tools/generate_dining_chair.py`
from `oak_dining_chair.json`. Other wood models inherit its geometry and replace
only the stripped side-grain texture. `all_wood_dining_chairs_preview.png` shows
all twelve finishes rendered from these shipped assets. Regenerating the preview does not register or
change any gameplay content.

- `oak_dining_chair_preview.png`: three-quarter, front, and side views.
- `oak_dining_chair.json`: Minecraft-format cuboid model used by the renderer.
- `generate_preview.py`: regenerates the model and preview using the vanilla
  Minecraft client jar. For the current target, pass the Minecraft 26.3 client jar with `--client-jar` to override the default cache path.

The armless design has three vertical back slats, square 2 × 2 legs, aprons,
side/rear stretchers, and a 14 × 14 seat with clipped corners. The seat top is
10 units above the floor; the back reaches 24 units (1½ blocks), so it rises
above the existing 16-unit dining table. The footprint stays within one block;
the back extends into the space above. The implemented block checks for floor
support and obstruction where the upper back extends. Sitting faces the player
toward the chair's front. The recipe uses `TTT` / `LLL` / `T T`, where T is stick
and L is a matching wood slab, and produces two chairs. The oak recipe JSON is
hand-editable; the production generator never overwrites it. Other wood recipes
copy its entire structure and substitute only the slab and output IDs.

All faces use `minecraft:block/stripped_oak_log`, the side-grain texture used by
stripped oak wood. This concept uses the raw vanilla texture, without a color
blend or end-grain rings. The software renderer reads the saved model geometry
and its explicit UV coordinates; images are model renders, not game screenshots.

Regenerate from the repository root (requires Pillow and NumPy):

```powershell
python preview/dining_chair/generate_preview.py
```
